# コンテンツの端末内暗号化を持たない

派生元にはパスフレーズによる E2EE があり、それが売りの一つだった。本製品では削除する。同期先が会社管理下の Google Workspace 共有ドライブであるため、暗号化は情報の保護ではなく統制の無効化として働くからである。暗号化されたファイルに対しては DLP も eDiscovery も保持ポリシーも監査も機能しない。加えて共有Vaultでは全員が同一のパスフレーズを共有することになり、個別の失効ができない。退職者が出るたびに全ファイルの再暗号化が必要になる。

守るべきものは端末そのものであって、会社が所有するドライブ上のファイルではない、という整理である。

## Consequences

- 資格情報はプラグインの data.json に平文で保存される。この経路は同期対象から常に除外する。共有すれば全員が互いの Google アカウントのリフレッシュトークンを持つことになるため、`.obsidian/` の除外は設定ではなく不変の制約として扱う。
- 後から E2EE を足すことはできるが、既に同期済みのファイルは平文のまま残る。導入するなら同期先を空にして最初からやり直すことになる。
