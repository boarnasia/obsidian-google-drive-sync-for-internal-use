# Google Drive Sync (Internal Use)

社内の Google Workspace 共有ドライブを介して、一つの Obsidian Vault をチームで共同利用するためのプラグインです。同期先は自社が所有するドライブだけで、第三者のサーバーを一切経由しません。

## 何をするものか

チームの誰かが書いたノートが、他のメンバーの Obsidian に届きます。逆も同じです。

- **同期先は共有ドライブのフォルダ。** その URL を貼るだけで指定できます。マイドライブか共有ドライブかはプラグインが判別して表示するので、貼り間違えたまま気づかない事故が起きません。
- **自分の Vault のどこを繋ぐかは自由。** 指定したフォルダの直下が、そのまま共有側の直下になります。フォルダ名は共有側に現れないので、各自が好きな名前を付けられます。個人用のノートを同じ Vault に同居させたままにできます。
- **データを失いません。** 削除はローカルもリモートもゴミ箱経由です。両方が変更されていた場合は、どちらも消さずに競合コピーとして残します。

何を比べて同期しているか、競合をどう決めるか、既知の問題は [同期の仕組み](docs/how-sync-works.md) にまとめています。

## 向いていない用途

**同じノートを複数人が同時に編集する用途には使えません。** ファイル単位の同期なので、同時編集は行単位でマージされず、片方が競合コピーに退避されます。担当や時間帯でノートが自然に分かれている使い方を想定しています。

リアルタイムの共同編集が必要なら、このプラグインではなく CRDT ベースの製品を検討してください。

## 前提

| 項目 | 要件 |
|---|---|
| Obsidian | 1.13.0 以上 |
| プラットフォーム | **デスクトップ専用**（iOS / Android では動作しません） |
| アカウント | Google Workspace のアカウントと、書き込み権限のある共有ドライブ |

サインインは `127.0.0.1` のループバック OAuth（PKCE）を使うため、モバイルでは原理的に動きません。

## インストール

[BRAT](https://github.com/TfTHacker/obsidian42-brat) を使います。

1. コミュニティプラグインから **BRAT** をインストールして有効化
2. コマンドパレット → `BRAT: Add a beta plugin for testing`
3. `boarnasia/obsidian-google-drive-sync-for-internal-use` を入力

以後は BRAT が自動で最新版に更新します。全員が同じバージョンで動くことは、同期の不具合を避けるうえで重要です。

## セットアップ

### 1. OAuth クライアント（情報システム部門が一度だけ作成）

このプラグインには認証情報が同梱されていません。社内で一つ OAuth クライアントを作り、ID とシークレットを社内に周知してください。

1. [Google Cloud Console → 認証情報](https://console.cloud.google.com/apis/credentials) でプロジェクトを選択または作成
2. **Google Drive API** を有効化
3. OAuth 同意画面の User Type を **Internal** に設定（社内限定になり、審査も 7 日でのトークン失効も発生しません）
4. **認証情報を作成 → OAuth クライアント ID**、種類は **デスクトップアプリ**

### 2. 各メンバーの設定

1. 設定 → Google Drive Sync (Internal Use)
2. **クライアント ID** と **クライアント シークレット** を貼り付け
3. **同期先のフォルダ URL** に、共有ドライブのフォルダの URL を貼り付け
   （例: `https://drive.google.com/drive/folders/15hq…`）
   表示された名前と「共有ドライブ『◯◯』内」が、他のメンバーと一致していることを確認してください
4. **ローカル同期フォルダ** に、自分の Vault のどのフォルダを繋ぐかを指定（空欄なら Vault 全体）
5. **接続** を押してブラウザで承認

## 同期されないもの

`.obsidian/`（Vault の設定ディレクトリ）は常に同期対象外です。ここにはこのプラグインの `data.json` があり、あなたの Google アカウントのリフレッシュトークンが入っています。共有するとメンバー全員が互いの認証情報を持つことになるため、設定で変更できないようにしてあります。

## 開発

```sh
npm ci
npm test          # vitest（オフライン。ネットワークも Google アカウントも不要）
npm run test:watch
npm run build     # 型検査 → main.js を生成
```

テストは `tests/` にあります。`obsidian` モジュールは `tests/helpers/obsidian-mock.ts` に、Drive と Vault はインメモリの偽物（`tests/helpers/`）に差し替わるため、資格情報も通信もなしに同期の往復まで通しで動きます。
